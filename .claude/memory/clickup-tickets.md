Tickets go into ClickUp (no connector here: copy-paste). Each ticket = title + short description, **plain text only**
(no `##`, no Markdown, no code blocks), visual explanation as simple text lines with arrows
(`before → after`, small examples), about 10 lines max. Don't generate tickets « for the sake of it »: group by topic.

**Why:** user found long Markdown descriptions « tooooo big » and unusable in ClickUp (2026-10-04).

**How to apply:** any new ticket request. Last batch (14 tickets: T1–T4 + D0–D9 done) is the private artifact
